# 손잡이 동아리 — 적정 기술 비주얼 노벨

호원중학교 3학년 2학기 기술 · 적정 기술 단원(12월~1월) 수업용 비주얼 노벨.
중1부터 졸업식까지 3년 동안 가상의 마을 「루미타」와 물 · 빛 · 음식 문제를 함께 풀고, 고른 길에 따라 10가지 졸업식 엔딩 중 하나를 맞는다.

- 성취기준: `[9기가05-09]` 적정 기술과 지속 가능 발전 (2015 개정 교육과정) · 성적 미반영
- 학생 화면: https://ict-handshake-club.netlify.app
- 교사 진행판: https://ict-handshake-club.netlify.app/host.html
- 모드: **전체 모드**(반 전체가 투표로 이야기를 정함) · **개인 모드**(크롬북으로 각자 끝까지)

## 구조

- `site/` — 배포하는 폴더(`index.html` 학생 · `host.html` 진행판 · `styles.css` · `img/` 그림 webp · `fonts/` Noto Serif KR 일부)
- `src/` — 코드. 이야기 지도는 `src/story.js` 하나
- `build.mjs` — esbuild 로 `src` → `site/dist` 묶기(Firebase SDK 포함)
- `database.rules.json` — 실시간 DB 보안 규칙(`/vn/rooms`)
- `test/` — 단위 시험(모든 길을 걸어 엔딩 10개 도달) · 가짜 DB(규칙 파일을 그대로 판정) · Playwright 부하 · 화면 시험(UI가 캐릭터 얼굴을 가리는지 검사)
- `tools/` — 그림 원본(png)을 webp 로 바꾸는 도구. 원본 그림은 이 저장소에 없다
- `docs/기획서.md` — 이야기 · 갈림길 · 엔딩 설계

## 실행 · 시험 · 배포

```bash
npm install
npm run build              # site/dist/ 생성
npm run serve              # 로컬에서 열어 보기
node test/unit.mjs         # 이야기 · 투표 · 규칙 단위 시험
node test/shots.mjs        # 화면 시험 (Playwright 필요)
netlify deploy --prod --no-build --dir site --site <site-id>
```

## 개인정보

학생 이름은 받지 않는다. 방 코드 4자리 + 번호(1~30)만 쓴다. 주인공 성별 · 이름은 학생 기기 안에만 있고 저장되지 않는다.
수업이 끝나면 방과 기록(투표 · 진행 · 성찰)을 모두 지운다.

## Firebase

실시간 DB + 익명 로그인. `src/net-firebase.js` 의 웹 설정값은 **공개되는 값**이며,
구글 클라우드 콘솔에서 API 키를 배포 주소로만 쓸 수 있게 제한해 두었다. 보안은 `database.rules.json` 이 맡는다.

## 그림

캐릭터 · 배경 · 엔딩 · UI 그림은 OpenAI Codex 이미지 생성으로 만들었다. 글꼴은 Noto Serif KR(SIL OFL).

# 「손잡이 동아리」 수업에서 쓰는 법 (교사용 한 장)

적정 기술 비주얼 노벨. 중1~중3 3년 동안 루미타 마을과 물 · 빛 · 음식 문제를 풀고, 마지막 장면은 언제나 졸업식이다.
갈림길 12번(주인공 고르기 1 + 이야기 11) · 엔딩 10개 · 성적 미반영.

| | 주소 |
|---|---|
| 학생 크롬북 | **https://ict-handshake-club.netlify.app** |
| 교사 진행판(큰 화면) | **https://ict-handshake-club.netlify.app/host.html** |

> 학생 이름은 받지 않는다. **방 코드 4자리 + 번호(1~30)** 만. 주인공 성별 · 이름은 학생 크롬북 안에만 있고 어디에도 저장되지 않는다.
> 「수업 끝」을 누르면 방과 학생 기록(투표 · 진행 · 성찰)이 모두 지워진다.

## 준비 (1분)

1. 교사 PC 에서 진행판 주소 → (시작 그림은 저절로 걷힘) **새 수업 시작** → **반(3-1~3-9)** · **방식** · **글 넘기는 속도** 고르기 → **방 만들기**
2. 큰 화면에 뜬 **방 코드**와 주소를 학생에게 → 학생은 크롬북에서 방 코드 + 내 번호 → 들어가기
3. 오른쪽 번호 칸에 ✓ 가 차면 **시작 ▶**

같은 번호로 두 기기가 들어오면 나중 기기가 남고 앞 기기는 「다른 기기에서 들어왔어요」가 뜬다(학생이 「다시 들어가기」로 되돌릴 수 있음).
같은 번호가 2분 안에 계속 바뀌면 자동으로 내보내지 않고 진행판에 「⚠ ○번이 두 기기예요(기기 글자)」가 뜬다 — 학생 화면 오른쪽 위 「기기 K7」 글자로 확인.

## 전체 모드 — 반 전체가 한 사람의 3년을 고른다 (약 30분)

- 큰 화면에 그림과 글이 **한 줄씩** 자동으로 나온다. 학생은 각자 눈으로 읽는다. 크롬북에는 「큰 화면을 보세요」.
- 갈림길이 오면: 「갈림길!」 → **💬 생각 시간 40초**(옆 친구와 이야기 · 교사가 「바로 투표 ▶」로 건너뛸 수 있음) → **투표 20초**(주인공 고르기 · 마지막 편지는 30초). 모두 냈으면 3초 뒤 바로 마감.
- **많이 고른 길**로 간다(과반이 아니라 최다 득표 · 안 낸 사람은 세지 않음). 진행판에는 「n / m명 냈어요」만 보이고, 누가 냈는지는 안 보인다. 마감 뒤 막대 3초.
- **동률이면** 동률인 길만 남겨 **15초 다시 투표** → 또 동률이면 **🎲 이야기 주사위**(모두가 보는 앞에서). 아무도 안 냈으면 바로 🎲. **빠르기로 가르지 않는다.**
- 주인공 고르기에서 「랜덤」이 이기면 🎲 로 남 · 여를 정한다. 이름은 기본 이름(한결 · 다온).
- 선택 뒤 「🤝 함께 +2」 같은 지표가 잠깐 뜨고, 친해진 사람 옆에 ♪ 가 뜬다(호감 숫자는 안 보인다).
- 졸업식 엔딩 → **엔딩 카드**(루미타의 불빛 · 기술 카드 · 우리 반이 간 길 · 갈림길마다 「다른 길 ○%」(그 길을 고르지 않은 사람 비율)) → **생각 정리(성찰) 열기 ▶** → 학생 답이 이름 없이 큰 화면에 모인다 → **수업 끝**.

진행판 위쪽 단추

| 단추 | 하는 일 |
|---|---|
| ⏸ 멈춤 / ▶ 자동 진행 | 멈추면 「다음 ▶」을 누를 때마다 한 줄씩(설명을 덧붙일 때) |
| 다음 ▶ (→ · 스페이스) | 지금 줄 · 단계를 바로 넘김. 생각 시간도 건너뜀 |
| 느리게 · 보통 · 빠르게 | 글 넘기는 속도. 진행 중에도 바꿀 수 있다 |
| 교사가 정하기 | 갈림길(생각 시간 · 투표 중)에서 교사가 바로 고른다 — 시간이 모자랄 때 |
| ⛶ | 전체 화면 |
| 수업 끝 | 방과 기록을 모두 지운다(되돌릴 수 없음) |

시간: 투표를 끝까지 기다리면 한 판 약 29분, 모두 빨리 내면 약 25분, 동률이 4번 나면 약 31분(시험 `test/unit.mjs` 계산).
남는 시간은 정리 활동(성찰 질문 · 기술 카드 다시 보기)에 쓴다.

**비상 모드(인터넷이 안 될 때)**: 시작 화면의 「비상 모드」 → 학생 투표 없이 손을 들게 하고 교사가 「이 길로」를 누른다. 이야기 · 엔딩은 같다.
**진행판을 실수로 새로 고쳤으면**: 시작 화면의 「이어서 하기」 → 그 장면부터 다시(투표 중이었으면 그 갈림길 투표를 다시 연다).

## 개인 모드 — 크롬북에서 각자 끝까지 (약 22~25분)

1. 시작 ▶ 을 누르면 학생 크롬북이 열린다: 주인공 고르기(남 · 여 · 랜덤) → 이름 보기 4개 중 고르기 → 이야기
2. 학생은 「다음 ▶」(또는 화면 · 스페이스)으로 글을 넘기고, 갈림길에서 직접 고른다. 소리 없음
3. 진행판: 「중1 · 중2 · 중3 · 졸업」 막대와 10칸 **엔딩 판**이 실시간으로 찬다(이름 · 번호 없음)
4. 졸업한 학생 → 내 엔딩 · 루미타의 불빛 · 기술 카드 → **성찰(생각 정리)** → 엔딩 도감(n/10) + 반 엔딩 통계 → 「다른 졸업식 찾기」(2회차, 읽은 장면은 넘기기 가능). **반 통계에는 첫 엔딩만** 들어간다
5. 교사가 **모두 졸업! ▶** → 반 통계 화면(엔딩 10칸 · 불빛 · 갈림길마다 가장 많이 고른 길). 아직 못 끝낸 학생 화면은 「선생님 화면을 보세요」
6. **성찰 모아 보기 ▶** → **수업 끝**

크롬북을 새로 고쳐도 그 자리에서 이어 간다(기기 안에 저장). 다른 크롬북으로 바꾸면 처음부터.

## 성찰 질문(두 모드 같음 · 2개 이상 쓰기 권장)

1. [의미] 「비싸고 새것」과 「마을에 딱 맞는 것」이 갈린 선택 하나 — 무엇이 달랐는지 (부제 「마을에 딱 맞는 기술 = 적정 기술」)
2. [지속가능 발전] 우리가 졸업한 뒤에도 루미타에 남아 계속 쓰일 기술과 그 까닭
3. [다음 차시] 우리 학교 · 동네의 불편 하나 + 적정 기술 생각 두 가지로 해결 방법 한 줄

답은 이름 없이 큰 화면에 모인다. 부적절한 답은 카드의 「가리기」(데이터에서도 지움). 수업 끝에 모두 지워진다.

## 알아 둘 것

- 한 반(31명)씩 쓴다. 무료 요금제라 **여러 반이 동시에 쓰지 않는다**(동시 연결 100 한도 · 대결 판과 같은 프로젝트)
- 게임 안에는 상표 이름이 없다(굴리는 물통 · 정수 빨대 …). 실제 사례 이름(Q드럼 · 라이프스트로 · 리터 오브 라이트 · 팟인팟)은 정리 슬라이드에서
- 반 기록판(시작 화면 오른쪽)은 교사 PC 에만 남는다

## 고치는 사람용

| 할 일 | 방법 |
|---|---|
| 글 · 선택지 · 효과 · 엔딩 고치기 | `src/story.js` 하나만 → `node test/unit.mjs`(길이 40자 · 엔딩 10개 도달 · 시간) → `npm run build` |
| 그림 새로 넣기 | `../그림/` 에 넣고 `python tools/art.py` → `npm run build` (없는 그림은 자리 그림으로 나온다) |
| 화면 꾸밈 그림(틀 · 단추 · 키 비주얼) | `../그림/UI/` · `../그림/타이틀/` → 같은 `python tools/art.py`. 키 비주얼을 바꾸면 `tools/ui_art.py` 의 `KV_FACES`(얼굴 상자)도 다시 잰다 |
| 제목 글꼴 | 이야기에 새 글자가 생기면 `python tools/font.py` (없는 글자는 시스템 글꼴로 보인다) |
| 시간 바꾸기 | `src/flow.js` 의 `T` |
| 시험 | `node test/unit.mjs` · `node test/rules.mjs` · `node test/load_class.mjs` · `node test/load_solo.mjs` · `node test/shots.mjs`(화면 + **얼굴 가림 검사**) (브라우저 시험은 **한 번에 하나씩**) |
| 배포 | `npm run build` 뒤 `netlify deploy --prod --no-build --dir site --site <site id>` |
