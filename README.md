# 손잡이 동아리 — 적정 기술 비주얼 노벨

호원중학교 3학년 2학기 기술 · 적정 기술 단원(12월~1월) 수업용 비주얼 노벨.
중1부터 졸업식까지 3년 동안 가상의 마을 「루미타」와 물 · 빛 · 음식 문제를 함께 풀고, 고른 길에 따라 10가지 졸업식 엔딩 중 하나를 맞는다.

- 성취기준: `[9기가05-09]` 적정 기술과 지속 가능 발전 (2015 개정 교육과정) · 성적 미반영
- 학생 화면: https://ict-handshake-club.netlify.app
- 교사 진행판: https://ict-handshake-club.netlify.app/host.html
- 모드: **전체 모드**(반 전체가 투표로 이야기를 정함) · **개인 모드**(크롬북으로 각자 끝까지)

## 구조

- `site/` — 배포하는 폴더(`index.html` 학생 · `host.html` 진행판 · `styles.css` · `img/` 그림 webp · `fonts/` Noto Serif KR 일부)
- `src/` — 코드. 이야기 지도는 `src/story.js` 하나
- `build.mjs` — esbuild 로 `src` → `site/dist` 묶기(Firebase SDK 포함)
- `database.rules.json` — 실시간 DB 보안 규칙(`/vn/rooms`)
- `test/` — 단위 시험(모든 길을 걸어 엔딩 10개 도달) · 가짜 DB(규칙 파일을 그대로 판정) · Playwright 부하 · 화면 시험(UI가 캐릭터 얼굴을 가리는지 검사)
- `tools/` — 그림 원본(png)을 webp 로 바꾸는 도구. 원본 그림은 이 저장소에 없다
- `docs/기획서.md` — 이야기 · 갈림길 · 엔딩 설계

## 실행 · 시험 · 배포

```bash
npm install
npm run build              # site/dist/ 생성
npm run serve              # 로컬에서 열어 보기
node test/unit.mjs         # 이야기 · 투표 · 규칙 단위 시험
node test/shots.mjs        # 화면 시험 (Playwright 필요)
netlify deploy --prod --no-build --dir site --site <site-id>
```

## 내 학교에서 쓰려면

이 저장소의 주소(Netlify · Firebase)는 호원중 수업용이고, 무료 요금제라 **동시 접속 100개**(약 세 반)까지만 된다.
그리고 Firebase 웹 키가 우리 배포 주소에서만 쓰이게 막혀 있다. 그래서 다른 학교에서는 **자기 Firebase 프로젝트로** 띄워야 한다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트 → **Realtime Database** 만들기(지역은 가까운 곳) → **Authentication → 익명** 사용 설정
2. 프로젝트 설정 → 웹 앱 추가 → 나오는 설정값(`apiKey` · `authDomain` · `databaseURL` · `projectId` 등)으로 `src/net-firebase.js` 의 값을 바꾼다
3. Realtime Database → 규칙 탭에 `database.rules.json` 내용을 그대로 붙여 넣고 **게시**
4. `npm install` → `npm run build` → `site/` 폴더를 Netlify 등 정적 호스팅에 올린다
5. (권장) 구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보 → 그 브라우저 키에 **웹사이트 제한**으로 내 배포 주소를 넣는다

- 학생 이름은 받지 않는다(방 코드 + 번호). 수업이 끝나면 진행판에서 방을 지운다
- 무료(Spark) 요금제로 충분하다. 한 번에 세 반 넘게 쓰면 동시 접속 100개에 걸릴 수 있다

## 개인정보

학생 이름은 받지 않는다. 방 코드 4자리 + 번호(1~99)만 쓴다. 주인공 성별 · 이름은 학생 기기 안에만 있고 저장되지 않는다.
수업이 끝나면 방과 기록(투표 · 진행 · 성찰)을 모두 지운다.

## Firebase

실시간 DB + 익명 로그인. `src/net-firebase.js` 의 웹 설정값은 **공개되는 값**이며,
구글 클라우드 콘솔에서 API 키를 배포 주소로만 쓸 수 있게 제한해 두었다. 보안은 `database.rules.json` 이 맡는다.

## 그림

캐릭터 · 배경 · 엔딩 · UI 그림은 OpenAI Codex 이미지 생성으로 만들었다. 글꼴은 Noto Serif KR(SIL OFL).

# 「손잡이 동아리」 수업에서 쓰는 법 (교사용 한 장)

적정 기술 비주얼 노벨. 중1~중3 3년 동안 루미타 마을과 물 · 빛 · 음식 문제를 풀고, 마지막 장면은 언제나 졸업식이다.
갈림길 12번(주인공 고르기 1 + 이야기 11) · 엔딩 10개 · 성적 미반영.

| | 주소 |
|---|---|
| 학생 크롬북 | **https://ict-handshake-club.netlify.app** |
| 교사 진행판(큰 화면) | **https://ict-handshake-club.netlify.app/host.html** |
| 혼자 하기(방 코드 · 진행판 없이) | **https://ict-handshake-club.netlify.app/alone.html** |

> 학생 이름은 받지 않는다. **방 코드 4자리 + 번호(1~99)** 만. 주인공 성별 · 이름은 학생 크롬북 안에만 있고 어디에도 저장되지 않는다.
> 「수업 끝」을 누르면 방과 학생 기록(투표 · 진행 · 성찰)이 모두 지워진다.

## 준비 (1분)

1. 교사 PC 에서 진행판 주소 → (시작 그림은 저절로 걷힘) **새 수업 시작** → **학생 수**(− / 숫자 / + 또는 20 · 24 · 26 · 28 · 30 · 32 · 35 단추, **1~99명** · 기본 28 · 지난번 값을 기억) · **방식** · **글 넘기는 속도** 고르기 → **방 만들기**
   - 학생 수를 넘는 번호(예: 24명인데 25번)는 크롬북에서 「우리 반 번호는 1~24번이에요」가 뜨고 들어올 수 없다. 대기실 번호 칸도 그 수만큼
2. 큰 화면에 뜬 **방 코드**와 주소를 학생에게 → 학생은 크롬북에서 방 코드 + 내 번호 → 들어가기
3. 오른쪽 번호 칸에 ✓ 가 차면 **시작 ▶**

같은 번호로 두 기기가 들어오면 나중 기기가 남고 앞 기기는 「다른 기기에서 들어왔어요」가 뜬다(학생이 「다시 들어가기」로 되돌릴 수 있음).
같은 번호가 2분 안에 계속 바뀌면 자동으로 내보내지 않고 진행판에 「⚠ ○번이 두 기기예요(기기 글자)」가 뜬다 — 학생 화면 오른쪽 위 「기기 K7」 글자로 확인.

## 전체 모드 — 반 전체가 한 사람의 3년을 고른다 (약 30분)

- 큰 화면에 그림과 글이 **한 줄씩** 자동으로 나온다. 학생은 각자 눈으로 읽는다. 크롬북에는 「큰 화면을 보세요」.
- 갈림길이 오면: 「갈림길!」 → **💬 생각 시간 40초**(옆 친구와 이야기 · 교사가 「바로 투표 ▶」로 건너뛸 수 있음) → **투표 20초**(주인공 고르기 · 마지막 편지는 30초). 모두 냈으면 3초 뒤 바로 마감.
- **많이 고른 길**로 간다(과반이 아니라 최다 득표 · 안 낸 사람은 세지 않음). 진행판에는 「n / m명 냈어요」만 보이고, 누가 냈는지는 안 보인다. 마감 뒤 막대 3초.
- **동률이면** 동률인 길만 남겨 **15초 다시 투표** → 또 동률이면 **🎲 이야기 주사위**(모두가 보는 앞에서). 아무도 안 냈으면 바로 🎲. **빠르기로 가르지 않는다.**
- 주인공 고르기에서 「랜덤」이 이기면 🎲 로 남 · 여를 정한다. 이름은 기본 이름(한결 · 다온).
- 선택 뒤 「🤝 함께 +2」 같은 지표가 잠깐 뜨고, 친해진 사람 옆에 ♪ 가 뜬다(호감 숫자는 안 보인다).
- 졸업식 엔딩 → **엔딩 카드**(루미타의 불빛 · 기술 카드 · 우리 반이 간 길 · 갈림길마다 「다른 길 ○%」(그 길을 고르지 않은 사람 비율)) → **생각 정리(성찰) 열기 ▶** → 학생 답이 이름 없이 큰 화면에 모인다 → **수업 끝**.

진행판 위쪽 단추

| 단추 | 하는 일 |
|---|---|
| ⏸ 멈춤 / ▶ 자동 진행 | 멈추면 「다음 ▶」을 누를 때마다 한 줄씩(설명을 덧붙일 때) |
| 다음 ▶ (→ · 스페이스) | 지금 줄 · 단계를 바로 넘김. 생각 시간도 건너뜀. 단추 · 설정 · 입력 칸에 커서가 있으면 키는 그 단추 몫(넘기지 않음) |
| **화면 아무 데나 누르기** (Enter) | 대사 · 장면 제목 · 지표 변화에서 다음 줄로. 글자가 찍히는 중이면 첫 누름은 글을 다 보여 주고, 다음 누름에 넘어간다. 두 번 빨리 눌러도 한 줄만. **갈림길 · 투표 · 결과 화면은 눌러도 넘어가지 않는다**(투표는 시간대로). 처음 한 번 「화면을 눌러도 다음 줄로 넘어가요」 안내가 잠깐 뜬다 |
| 🎵 · 🔊 · ⚙ 설정 | 🎵 음악 켜기/끄기 · 🔊 효과음 켜기/끄기 · ⚙ 설정 판(곡 1 · 2 · 3 · 크기 · 움직임) — 아래 「소리 · 움직임 설정」 |
| 느리게 · 보통 · 빠르게 | 글 넘기는 속도. 진행 중에도 바꿀 수 있다 |
| 교사가 정하기 | 갈림길(생각 시간 · 투표 중)에서 교사가 바로 고른다 — 시간이 모자랄 때 |
| ⛶ | 전체 화면 |
| 수업 끝 | 방과 기록을 모두 지운다(되돌릴 수 없음) |

시간: 투표를 끝까지 기다리면 한 판 약 29분, 모두 빨리 내면 약 25분, 동률이 4번 나면 약 31분(시험 `test/unit.mjs` 계산).
남는 시간은 정리 활동(성찰 질문 · 기술 카드 다시 보기)에 쓴다.

**비상 모드(인터넷이 안 될 때)**: 시작 화면의 「비상 모드」 → 학생 투표 없이 손을 들게 하고 교사가 「이 길로」를 누른다. 이야기 · 엔딩은 같다.
**진행판을 실수로 새로 고쳤으면**: 시작 화면의 「이어서 하기」 → 그 장면부터 다시(투표 중이었으면 그 갈림길 투표를 다시 연다).

## 개인 모드 — 크롬북에서 각자 끝까지 (약 22~25분)

1. 시작 ▶ 을 누르면 학생 크롬북이 열린다: 주인공 고르기(남 · 여 · 랜덤) → 이름 보기 4개 중 고르기 → 이야기
2. 학생은 화면 아무 데나 누르거나 「다음 ▶」 · 스페이스 · Enter · → 로 글을 넘기고, 갈림길에서는 단추로 직접 고른다. 소리는 처음엔 꺼짐(머리띠 🎵 · 🔊 로 켬 · 이어폰 권장)
3. 진행판: 「중1 · 중2 · 중3 · 졸업」 막대와 10칸 **엔딩 판**이 실시간으로 찬다(이름 · 번호 없음)
4. 졸업한 학생 → 내 엔딩 · 루미타의 불빛 · 기술 카드 → **성찰(생각 정리)** → 엔딩 도감(n/10) + 반 엔딩 통계 → 「다른 졸업식 찾기」(2회차, 읽은 장면은 넘기기 가능). **반 통계에는 첫 엔딩만** 들어간다
5. 교사가 **모두 졸업! ▶** → 반 통계 화면(엔딩 10칸 · 불빛 · 갈림길마다 가장 많이 고른 길). 아직 못 끝낸 학생 화면은 「선생님 화면을 보세요」
6. **성찰 모아 보기 ▶** → **수업 끝**

크롬북을 새로 고쳐도 그 자리에서 이어 간다(기기 안에 저장). 다른 크롬북으로 바꾸면 처음부터.

## 혼자 하기 — 방 코드 없이 혼자 끝까지 (약 25분)

`alone.html` 을 열면 바로 시작 화면이다. 방 · 진행판 · 서버가 없고 갈림길은 혼자 고른다. **소리 · 목소리는 켜진 채로 · 움직임 상**으로 시작한다(첫 누름부터 소리가 난다).

- **남는 것은 엔딩 기록뿐**: 어떤 엔딩을 봤는지만 그 브라우저에 저장되고(`vn.alone.dex`), 시작 화면 「엔딩 도감 n / 10」으로 본다. 소리 설정은 따로 기억한다
- **중간 저장은 없다**: 창을 닫거나 새로 고치면 이야기는 처음부터. 성찰 · 반 통계도 없다
- 위쪽 「처음 화면」으로 나갈 수 있다. 다른 컴퓨터 · 다른 브라우저로는 기록이 옮겨 가지 않는다

## 소리 · 움직임 설정 (음악 · 효과음은 코드로 만듦 — 내려받은 파일 없음)

| 화면 | 처음 설정 |
|---|---|
| 진행판(큰 화면) | 움직임 **상** · 음악 켬(작게) · 효과음 켬. **처음 한 번 화면을 눌러야** 소리가 난다(브라우저 규칙) — 시작 그림이나 「새 수업 시작」을 누르면 된다 |
| 전체 모드 크롬북 | 움직임 **하** · **늘 소리 없음**(소리 단추 없음 · ⚙ 에는 움직임만) — 30대가 한꺼번에 울리지 않게. 소리는 큰 화면에서만 |
| 개인 모드 크롬북 | 움직임 **하** · 소리 처음엔 끔. 머리띠 🎵(음악) · 🔊(효과음) · ⚙ 로 학생이 바꿀 수 있다 |

- **어디에**: 머리띠 오른쪽 **🎵 · 🔊 · ⚙ 설정**(시작 화면에서는 아래쪽 띠). 🎵 · 🔊 는 바로 켜고 끈다(꺼진 단추에는 ✕). **⚙ 설정**을 누르면 머리띠 바로 아래에 한 줄이 열린다(화면을 밀어 내림 — 그림 · 얼굴을 덮지 않음): 🎵 배경음악 켬/끔 · 곡 1 · 2 · 3 · 크기 / 🔊 효과음 켬/끔 · 크기 / ✨ 움직임 상 · 중 · 하 · 끄기
- **움직임 4단계**(바꾸면 바로 적용 · 그 컴퓨터에 기억)

| 단계 | 화면 |
|---|---|
| **상** | 전부 — 날씨 알갱이(비 · 눈 · 반딧불 · 별 · 꽃잎 · 먼지 빛 · 햇살 · 물 반짝, 최대 약 120개) · 말하는 사람은 밝게 앞으로 · 숨쉬기 · 배경 천천히 밀기 · 장 제목(「중2 · 겨울」) · 글자 강조 · 기술 성공 빛 + 카메라 밀기 · 투표 연출(차례로 등장 · 마지막 3초 두근 · 막대 · 도장) · 설렘 분홍 테두리 · 엔딩(그림 줌아웃 · 빛 번짐 · 꽃가루 → 글 칸) |
| **중** | 알갱이 절반(최대 약 50개) · 숨쉬기만 · 흔들림 · 카메라 밀기 없음 |
| **하** | 나타나기 · 밀려오기만(알갱이 · 숨쉬기 · 배경 밀기 없음) |
| **끄기** | 움직임 없음(바로 바뀜). 컴퓨터의 「움직임 줄이기」를 켜 두면 처음 값이 끄기 |

- 음악 5곡: **여는 곡 「여는 이야기」**(시작 · 수업 설정 · 대기실) → 이야기 동안 **고른 곡 하나** — ① 「봄 교정」 오르골 · ② 「루미타 바람」 마림바 · 기타(6/8) · ③ 「동아리방 오후」 전자 피아노 로파이 → 엔딩 장면부터 엔딩 카드 · 성찰까지 **엔딩 곡 「졸업 편지」**. 곡을 바꾸면 바로 스르륵 바뀐다. 밤 장면은 더 작고 부드럽게, 문제가 터진 장면은 조금 어둡게
- 효과음: 글 넘김 「톡」 · 장면 바뀜 · 투표 열림 · 마지막 3초 · 결과 공개 · 동률 · 주사위 · 지표 오름 · 기술이 켜짐 · 엔딩 종소리
- 효과음은 효과마다 짝이 있다(말하는 사람 바뀜 · 장 제목 · 느낌표 · 속마음 · 기술 반짝/성공 · 선택지 등장 · 마우스 올림(자주 안 울림) · 고름 · 마지막 3초 두근 · 막대 북 굴림 · 이긴 길 도장 · 설렘 · 엔딩). 날씨마다 작은 환경음(비 · 밤 · 바람 · 방)도 효과음을 따라 켜지고 꺼진다
- 설정(켜기 · 곡 · 크기 · 움직임)은 그 컴퓨터에 기억된다. 탭을 다른 데로 옮기면 소리가 멈춘다
- **🗣 목소리(풀 보이스)**: 인물 대사와 해설을 녹음으로 읽어 준다(Gemini 음성으로 미리 만든 `site/voice/*.ogg` 317개 · 약 23분 · 5.5MB). 진행판은 처음부터 켬 · 개인 모드 크롬북은 처음엔 끔(이어폰을 끼고 🗣 로 켬) · 전체 모드 크롬북은 늘 소리 없음. ⚙ 설정에서 목소리 켜기 · 크기 · 「해설 읽기」 따로 끄기. 말하는 동안 배경음악은 30% 작아진다. 전체 모드는 줄마다 녹음이 끝날 때까지(+0.45초) 기다렸다 넘어간다 — 한 판 시간은 거의 같다. 글을 고치면 그 줄은 녹음이 없어져 소리 없이 글만 나온다(다시 녹음해야 함)

## 화면 효과

장면이 바뀔 때 넘김(학년 · 달이 바뀌면 책장 넘기기) · 인물 들어오기 · 말하는 사람 깡충 · 감정 표시(✨ 💡 💧 ♪ — 머리 **옆**) · 놀람 장면 흔들림 · 기술이 켜지면 빛 · 지표 「+2 함께」 · 배경마다 날씨(빗물 탱크 비 · 눈 · 밤 반딧불 · 봄 꽃잎 · 동아리방 먼지 빛) · 투표 막대 차오름 · 엔딩 꽃가루. **어떤 효과도 인물 얼굴을 덮지 않는다**(날씨는 인물 뒤에 그리고 머리 둘레는 비워 둔다). ⚙ 설정의 움직임 「끄기」(또는 컴퓨터 「움직임 줄이기」)면 날씨 · 흔들림 · 글자 찍기 · 꽃가루가 모두 꺼진다.

엔딩 장면: 엔딩 그림은 자르지 않고 크게, 글은 옆(4:3 화면은 아래) 종이 칸에 큰 글씨로. 칸 맨 위에 「졸업식 · 엔딩 n · 이름」, 지난 줄은 조금 작게(큰 화면에서 20px 이상) · 지금 줄은 크고 굵게. 칸이 모자라면 오래된 줄부터 숨겨 지금 줄은 늘 다 보인다.

## 성찰 질문(두 모드 같음 · 2개 이상 쓰기 권장)

1. [의미] 「비싸고 새것」과 「마을에 딱 맞는 것」이 갈린 선택 하나 — 무엇이 달랐는지 (부제 「마을에 딱 맞는 기술 = 적정 기술」)
2. [지속가능 발전] 우리가 졸업한 뒤에도 루미타에 남아 계속 쓰일 기술과 그 까닭
3. [다음 차시] 우리 학교 · 동네의 불편 하나 + 적정 기술 생각 두 가지로 해결 방법 한 줄

답은 이름 없이 큰 화면에 모인다. 부적절한 답은 카드의 「가리기」(데이터에서도 지움). 수업 끝에 모두 지워진다.

## 알아 둘 것

- 방 하나 = 학생 최대 99명 + 진행판(대기실 번호 칸은 31명부터 촘촘해지고, 넘치면 칸 안에서 스크롤). 무료 요금제라 동시 연결은 100까지(대결 판과 합산 · 약 세 반이 한꺼번에)
- 게임 안에는 상표 이름이 없다(굴리는 물통 · 정수 빨대 …). 실제 사례 이름(Q드럼 · 라이프스트로 · 리터 오브 라이트 · 팟인팟)은 정리 슬라이드에서
- 반 기록판(시작 화면 「반 기록판」)은 교사 PC 에만 남는다. 반 이름 대신 **날짜 · 시각 · 방식 · 결과**로 적는다
- 다른 선생님이 같은 사이트를 동시에 써도 방 코드(무작위 4자리 · 겹침 검사)로 나뉜다

|---|---|
| 글 · 선택지 · 효과 · 엔딩 고치기 | `src/story.js` 하나만 → `node test/unit.mjs`(길이 40자 · 엔딩 10개 도달 · 시간) → `npm run build` |
| 그림 새로 넣기 | `../그림/` 에 넣고 `python tools/art.py` → `npm run build` (없는 그림은 자리 그림으로 나온다) |

| 제목 글꼴 | 이야기에 새 글자가 생기면 `python tools/font.py` (없는 글자는 시스템 글꼴로 보인다) |
| 시간 바꾸기 | `src/flow.js` 의 `T` |

| 화면 효과 고치기 | `src/fx.js`(날씨 · 감정 표시 · 흔들림 · 글자 찍기 · 넘기기 판정) · `site/styles.css` 끝 |
